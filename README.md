# PyTorch MNIST Neural Network

This project implements a Multi-Layer Perceptron (MLP) neural network for classifying handwritten digits from the MNIST dataset using PyTorch.

## Features

- Loads and preprocesses the MNIST dataset
- Implements a fully-connected neural network with multiple hidden layers
- Trains the model with SGD optimizer
- Evaluates model performance on test data
- Saves the best model during training
- Visualizes training and test loss/accuracy metrics in real-time

## Requirements

- Python 3.6+
- PyTorch 1.12.0+
- torchvision 0.13.0+
- matplotlib 3.5.0+
- Other dependencies in `requirements.txt`

## Usage

1. Install dependencies:
   ```
   pip install -r requirements.txt
   ```

2. Run the training script:
   ```
   python mnist_classifier.py
   ```

3. Visualize final training metrics:
   ```
   python visualize_metrics.py
   ```

The training script will automatically:
- Download the MNIST dataset
- Train the model for the specified number of epochs
- Save the best model as `mnist_model.pt`
- Record and save training metrics to `training_metrics.json`
- Generate and update a single plot after each epoch showing both loss and accuracy trends

The visualization script will generate:
- Loss curves (training and test)
- Accuracy curve (training and test)
- Combined metrics plot
- Summary of training results

## Model Architecture

The MLP architecture used in this project:
- Input layer: 784 neurons (flattened 28×28 MNIST images)
- First hidden layer: 512 neurons with ReLU activation and dropout (0.3)
- Second hidden layer: 256 neurons with ReLU activation and dropout (0.3)
- Third hidden layer: 128 neurons with ReLU activation and dropout (0.2)
- Output layer: 10 neurons (one for each digit) with Log Softmax activation

## Visualization Outputs

The visualization includes:

### Real-time Plot (Updated After Each Epoch)
A single plot is generated and continuously updated during training:
- `training_progress.png` - Shows training/test loss and training/test accuracy

The plot is divided into two sections:
1. Top section: Training and test loss over epochs
2. Bottom section: Training and test accuracy over epochs

### Final Plots (Generated by visualize_metrics.py)
1. `loss_curves.png` - Training and test loss over all epochs
2. `accuracy_curve.png` - Training and test accuracy over all epochs
3. `combined_metrics.png` - Combined view of all metrics

This visualization approach allows you to track both training and test performance in real-time with a single, comprehensive plot.
